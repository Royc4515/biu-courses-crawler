# סורק קטלוג הקורסים של אוניברסיטת בר-אילן (Universal BIU Course Catalog Crawler)

סורק אוניברסלי ועצמאי המאפשר סריקה, חילוץ נתונים והשוואת קטלוג הקורסים של **כל מחלקה או פקולטה** באוניברסיטת בר-אילן עבור כל שנת לימודים (תשפ"ז / 2027 ואילך).

---

## 📁 מבנה הקבצים בפרויקט

| קובץ | תיאור |
| :--- | :--- |
| **`catalog-meta.js`** | מאגר מטא-דאטה של כל 11 הפקולטות ו-66 המחלקות בבר-אילן, כולל מזהים (IDs), שמות וכינויים (slugs). |
| **`crawl.js`** | סקריפט Node.js גנרי המתחבר ל-Chrome דרך פורט 9222 ומבצע סריקה מלאה לפי מחלקה/פקולטה/חיפוש פעיל. |
| **`browser-crawl.js`** | סקריפט עצמאי להרצה ישירה ב-Console של הדפדפן, כולל חלונית בחירה אינטראקטיבית, באנר התקדמות והורדת קובץ אוטומטית. |
| **`compare.js`** | סקריפט גנרי להשוואה בין שני קובצי סריקה של אותה מחלקה/פקולטה והפקת דוח שינויים (`diff-report.json`). |
| **`biu-*.json`** | קובצי ה-JSON המלאים שהופקו בסריקות (כולל מטא-דאטה, שורות קורסים, סקשנים, מרצים, מועדי בחינות וסילבוסים). |

---

## 🔍 הצגת רשימת המחלקות והפקולטות הזמינות

כדי לראות את כל המזהים והשמות של הפקולטות והמחלקות:

```bash
node crawl.js --list
# או
npm run crawl:list
```

## 🚀 דרכי הרצה

### אפשרות 1: הרצה דרך Node.js עם Chrome קיים (מומלץ)

מכיוון שאתר הקורסים של בר-אילן מוגן ע"י Radware Bot Manager ו-hCaptcha, הדרך היציבה ביותר היא לפתוח Chrome עם פורט דיבאג ולתת לסקריפט לרוץ מתוכו:

1. **פתיחת Chrome עם פורט דיבאג:**
   ```cmd
   chrome.exe --remote-debugging-port=9222
   ```

2. **ניווט לאתר הקורסים ופתרון אתגר במידת הצורך:**
   פתח טאב בכתובת `https://courses.biu.ac.il/`.

3. **הפעלת הסורק עבור כל מחלקה או פקולטה:**

   ```bash
   # סריקת מחלקה לפי מזהה (לדוגמה: 84 = מדעי המחשב)
   node crawl.js --dept 84

   # סריקת מחלקה לפי שם בעברית או slug באנגלית
   node crawl.js --dept "מדעי המחשב"
   node crawl.js --dept math
   node crawl.js --dept psychology

   # סריקת פקולטה מלאה (לדוגמה: 10 = הנדסה, 5 = משפטים, 4 = מדעים מדויקים)
   node crawl.js --faculty 10
   node crawl.js --faculty "הנדסה"
   node crawl.js --faculty exact-sciences

   # ציון שנת לימודים אחרת (ברירת מחדל: 2027)
   node crawl.js --dept 84 --year 2026

   # הרצה אינטראקטיבית: אם אתה כבר בדף תוצאות חיפוש בדפדפן - יסרוק אותו ישירות!
   node crawl.js
   ```

4. הסקריפט יסרוק את כל העמודים, ישלוף את פרטי כל הקורסים בהשהייה בטוחה (1.5 שניות), וישמור קובץ בשם:
   `biu-<year>-<slug>-full-<YYYY-MM-DD>.json` (לדוגמה: `biu-2027-cs-full-2026-10-14.json` או `biu-2027-engineering-full-2026-10-14.json`).

---

### אפשרות 2: הרצה עצמאית ישירות מ-DevTools ב-Chrome (ללא Node.js)

אם אינך מעוניין להפעיל תהליך Node.js:

1. פתח את אתר הקורסים בדפדפן הרגיל שלך:
   `https://courses.biu.ac.il/`
2. לחץ `F12` במקלדת ועבור ללשונית **Console**.
3. העתק את כל התוכן של [`browser-crawl.js`](./browser-crawl.js), הדבק ב-Console ולחץ `Enter`.
4. **אם אתה בדף החיפוש הראשי:** תיפתח חלונית גרפית צפה המאפשרת לבחור שנה, מחלקה או פקולטה וללחוץ **"התחל סריקה 🚀"**.
5. **אם ביצעת חיפוש ידני ואתה כבר בדף התוצאות:** הסקריפט יזהה מיד את הקורסים ויתחיל בסריקה אוטומטית.
6. בסיום, הקובץ המלא יירד אוטומטית למחשב שלך.

כמו כן, ניתן לקרוא לפונקציה מתוך ה-Console בכל שלב:
```javascript
crawlBIU({ dept: 84, year: '2027' });       // סריקת מדעי המחשב
crawlBIU({ faculty: 10, year: '2027' });    // סריקת הנדסה
crawlBIU();                                 // סריקת התוצאות הפעילות במסך
```

## 📊 הרצת השוואה ובדיקת שינויים (`compare.js`)

כדי להשוות בין סריקות שונות (למשל סריקה חדשה מול סריקת ייחוס קודמת):

```bash
# השוואה אוטומטית בין שתי הסריקות העדכניות ביותר של אותה מחלקה
npm run compare
# או
node compare.js

# השוואת מחלקה ספציפית לפי slug
node compare.js cs
node compare.js engineering

# השוואה בין שני קבצים ספציפיים
node compare.js biu-2027-cs-full-2026-09-13.json biu-2027-cs-full-2026-10-14.json
```

הסקריפט יציג סיכום במסוף וישמור דוח מפורט ב-`diff-report.json`.

## 🔒 כללי אתיקה ובטיחות
- קצב הסריקה מוגבל כברירת מחדל ל-1,500 מ"ש בין בקשות (`--delay 1500`).
- הקבצים כוללים נתוני קטלוג ציבוריים בלבד.
- שמירה תקופתית לנקודת ביקורת (`checkpoint-<slug>.json`) מונעת איבוד נתונים במקרה של ניתוק רשת.
